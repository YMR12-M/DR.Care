# نظام التصميم — «خط الغسيل»

الهوية البصرية لـ DR.Care بتتحكي بلغة المغسلة نفسها، مش بقالب «داكن + دهبي» عام. الفكرة: **المغسلة كواجهة** — أرضية أسفلت مبلولة، لافتات صفراء تحذيرية، تذاكر ورق، لوحات أرقام مصرية، شاشات LED، ولافتة نيون واحدة (اللوجو).

> الأصل: لوجو DR.Care نفسه نيون (إطار أصفر + دش سيان + عربية ماجنتا)، وصورة المغسلة فيها خطوط تحذير صفراء/سودا ورغوة. التصميم الجديد بيطلع من الحاجات دي.

---

## 1. المبادئ

| ✅ اعمل | ❌ متعملش |
|---|---|
| ألوان مسطّحة + حواف حادة (radius 6–12px) | gradients ذهبية، glass/blur، glow، noise overlay |
| ظل صلب `0 4px 0 rgba(0,0,0,.45)` لو لازم | ظل ناعم/متوهج |
| توهّج **فقط** لما في مصدر ضوء حقيقي: النيون و LED | `text-shadow`/`box-shadow` ملوّن للزينة |
| أرقام غربية (`150`) في كل مكان | أرقام هندية، **إلا** في لوحة الأرقام (`Plate`) |
| `font-weight: 400` مع Lalezar (وزن واحد) | bold على Lalezar (بيطلع faux-bold) |
| `letter-spacing: 0` على أي نص عربي | تباعد حروف عربي — بيكسر الاتصال |
| ألوان الخدمات = أصفر واحد | ألوان قوس قزح لكل خدمة، أيقونات في مربعات متدرجة، إيموجي كعناصر واجهة |

## 2. الألوان (tokens)

نفس الأسماء القديمة (`--yellow`, `--panel-2`, `--muted`…) عشان أي كود قديم يلتقط الألوان الجديدة تلقائياً.

| Token | القيمة | الاستخدام |
|---|---|---|
| `--black` | `#0d0f12` | خلفية الصفحة (أسفلت، مش أسود صافي) |
| `--panel` / `--panel-2` / `--panel-3` | `#14161a` / `#1b1e23` / `#262a31` | أسطح، كروت، حقول |
| `--steel` | `#3a3f48` | حواف اللوحات |
| `--yellow` | `#ffd21f` | لون البراند — أسطح لافتات، أزرار، أسعار |
| `--on-yellow` | `#111214` | نص/حدود فوق الأصفر |
| `--paper` / `--paper-ink` | `#f3f0e6` / `#111214` | التذاكر والإيصالات (فوم/ورق) |
| `--water` `--neon-y` `--neon-p` | `#46c9e7` `#f4ee55` `#f13fa0` | **ألوان النيون من اللوجو** — استخدمها بندرة |
| `--plate` | `#1c4ea6` | أزرق لوحة العربية |
| `--success` / `--error` | `#58d68d` / `#ff5a4d` | حالات فقط |

## 5. أماكن الملفات

**الويب** (يتحمّلوا بالترتيب ده):
`assets/css/styles.css` (قديم/أساسي) → `assets/css/brand.css` (النظام المشترك: tokens، هيدر، أزرار، حقول، auth، toast، فوتر، تأثير على الصفحات الثانوية) → `assets/css/home.css` (الصفحة الرئيسية فقط).
JS: `assets/js/brand.js` (لافتة المفتوح، العربية على خط الغسيل مع السكرول، مزامنة أسعار القايمة مع `api/packages.php`).
أصول: `assets/img/brand/sprite.svg`.

**التطبيق** (`mobile-app/src`): `index.css` (tokens + مكوّنات CSS + keyframes) · `components/brand/*` · `components/ui/*` (Button, Card, Input… بنفس الأسماء القديمة) · `lib/format.js` (أرقام/لوحة/وقت المغسلة) · `lib/bidi.jsx`.

## 6. أحكام عملية

- **اتجاه الحركة = يمين لشمال** (RTL): العربية على خط الغسيل بتبدأ يمين، والشريط المتحرك بيمشي ناحية اليمين (زي أخبار العربي).
- **كلمات إنجليزي جوه نص عربي** (زي «غسيل متخصص (Deep Cleaning)»): استخدم `<Mixed>` (`lib/bidi.jsx`) عشان القوس يطلع صح.
- **`prefers-reduced-motion`** مدعوم عالمياً — أي حركة جديدة لازم تحترمه.
- **تباين**: النص الباهت على الورق `--paper-mute #6b6552`، وعلى الأسود `--muted #9aa1ac`.
- **الأيقونات**: للوظيفة بس (Lucide: سهم، تليفون، خريطة…). الزينة بتتعمل بالأشكال الخاصة (تذكرة، لوحة، عربية، خط).

## 7. اللي لسه ما اتلمسش (خطوات جاية)

- `CarWash-POS/` (نقطة البيع) — ليها stylesheet مستقل.
- `mobile*.html` القديمة و`index-2.html` — لسه بالتصميم القديم.
- الصفحات الثانوية (عملاء، تتبع، FAQ، معرض، إحالة، أدمن) اتاخدت من `brand.css` على مستوى الـtokens والهيدر والأزرار والهيرو فقط؛ لسه فيها إيموجي في بعض الأيقونات (إحالة، مستويات الولاء) وعناصر محتاجة تصميم مخصّص بنفس اللغة.
- نسخة التطبيق `/app` بتتبني في Docker (`mobile-app/dist` → `/app`)؛ محلياً شغّل `npm --prefix mobile-app run dev` والخادم PHP على `:8000`.
